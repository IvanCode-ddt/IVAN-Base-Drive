Nguồn phát phim / nhạc (tùy chọn)

URL HTML5 phải trỏ trực tiếp tới media HTTPS được phép phát. Không dùng link tải Drive làm stream. Với Drive, nhập link Preview/View của file đã gắn và đã xác nhận công khai. Không nhập HTML iframe hoặc token.

Thông tin nội dung / file (tùy chọn)

Chỉ nhập thông tin bạn biết chính xác. Tên, MIME type, dung lượng và ngày file tự lấy từ các file Drive đã được xác nhận công khai.
